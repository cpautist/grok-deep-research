# Report template (v2.1)

Two layers. Layer A is the product. Layer B is ground support. Do not invert them.

## Layer A

```markdown
# [Title: object + bound, not the mode]

*[Mode]. Decision this informs: .... Cutoff ....*

[One-sentence nut graf.]

## Executive answer

[12-15 lines of prose. Confidence on the pattern vs confidence on any single document. No Claim/Evidence/Credence labels.]

## What would change this answer

- [Disconfirmation test 1]
- [Disconfirmation test 2]
- [Disconfirmation test 3]

## [Topic-native H2]

[Finding in the first sentence. Decisive evidence next. Why the distinction matters. Residual uncertainty in the same section.]

[At least one content table in Standard+: timeline, comparison, disambiguation, or numbers-with-vintage.]

## [Further topic-native H2s]

## Conclusion

[Answer the P0 decision. Known / not known. What a careful reader should and should not infer. Next instrument if an unknown is load-bearing.]
```

## Layer B

```markdown
## How this was researched

Queries, pages opened, sources rejected and why, stop reason.

## Compact claim ledger

| Claim | Status | Credence | Independence groups | Vintage |
|---|---|---|---|---|
| ... | supported / contested / unsupported / unknown | ... | ... | ... |
```

Scout may omit Layer B. Standard keeps Layer B short. Deep/Ultra print it in full.

Forbidden in Layer A: Q1-Q12 headings, repeating Claim/Evidence/Credence triplets, Mode: as the title, process-speak (opened page, atomic question, this session).
